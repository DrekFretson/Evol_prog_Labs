# Лабораторная работа №2 — вариант 5

## Тема
**Генетический алгоритм для дискретной задачи с ограничениями.**

Индивидуальный вариант: **выбор комплекта оборудования для лаборатории при бюджете, мощности и совместимости**.

Проект рассчитан на Python и PyCharm. Ключевые части генетического алгоритма реализованы самостоятельно, без DEAP, PyGAD и других готовых библиотек эволюционной оптимизации.

## Постановка

Есть 40 единиц оборудования. Для каждой заданы цена, потребляемая мощность и полезность. Некоторые пары оборудования несовместимы. Нужно максимизировать суммарную полезность выбранного комплекта при ограничениях:

- суммарная стоимость не более **2 000 000 руб.**;
- суммарная мощность не более **18 000 Вт**;
- ни одна конфликтующая пара не может быть выбрана одновременно.

Хромосома — бинарный вектор длины 40. `1` означает, что оборудование входит в комплект, `0` — не входит.

Входные данные синтетические, что разрешено заданием. Они сгенерированы один раз с фиксированным seed `20260927` и сохранены в `data/equipment.csv`; поэтому эксперименты воспроизводимы. Конфликты явно сохранены в `data/conflicts.csv`.

## Реализованный генетический алгоритм

- популяция: 80;
- поколений: 250;
- турнирная селекция (`k=3`);
- элитизм: 2 особи;
- вероятность кроссовера: 0.9;
- вероятность битовой мутации каждого гена: 0.03;
- 20 независимых запусков;
- фиксированные seed для воспроизводимости.

Реализованы два кроссовера: **равномерный** и **одноточечный**.

Реализованы два подхода к ограничениям:

1. **Repair** — после вариации конфликтующие и избыточные позиции удаляются до получения допустимого решения.
2. **Penalty** — недопустимая особь сохраняется, но fitness уменьшается за превышение бюджета, мощности и конфликты.

Это позволяет отдельно выполнить обязательное сравнение способов обработки ограничений и сравнение операторов кроссовера.

## Baseline

Реализована простая жадная эвристика. Оборудование сортируется по отношению полезности к нормированной стоимости ресурсов, после чего позиции последовательно добавляются, если ограничения остаются выполненными.

## Установка и запуск в PyCharm

Открыть папку `Evol_prog_Labs` или непосредственно `lab_2` в PyCharm. Рекомендуется отдельное виртуальное окружение.

В терминале:

```powershell
cd lab_2
python -m pip install -r requirements.txt
python main.py
```

Программа автоматически выполняет полную серию экспериментов и сохраняет результаты.

## Что сравнивается

`GA_repair_uniform` и `GA_penalty_uniform` отличаются только способом обработки ограничений — repair против penalty.

`GA_repair_uniform` и `GA_repair_onepoint` отличаются только оператором кроссовера — равномерный против одноточечного.

Таким образом, при анализе можно делать корректные попарные сравнения, не смешивая сразу несколько факторов.

## Допустимость

Решение считается допустимым, если одновременно:

```text
price <= 2 000 000
power <= 18 000
conflicts == 0
```

В `examples.csv` автоматически сохраняются примеры допустимых и недопустимых хромосом.

## Воспроизводимость

Данные имеют фиксированный seed. Для независимых запусков используются seed `2505..2524`. При одинаковой версии Python и параметрах алгоритма результаты воспроизводимы.

## Краткий алгоритм

1. Загрузить данные.
2. Создать бинарную популяцию.
3. Оценить полезность и ограничения.
4. Выбрать родителей турнирной селекцией.
5. Выполнить crossover.
6. Выполнить bit-flip mutation.
7. Применить repair либо penalty.
8. Сохранить элиту.
9. Повторить до 250 поколений.
10. Повторить эксперимент 20 раз.
11. Рассчитать статистику, сравнить варианты и baseline.
