# Отчёт по лабораторной работе №1

## 1. Постановка задачи

В лабораторной работе выполняется многомерная оптимизация сложной функции генетическим алгоритмом.

Индивидуальный вариант:

```text
V = 19
```

Размерность определяется следующим образом:

```text
d = 5 + (V mod 6)
```

Следовательно:

```text
d = 5 + (19 mod 6) = 6
```

Для варианта 19 используется функция HappyCat:

```text
f(x) =
|Σ(x_i²) - d|^(1/4)
+
(0.5 * Σ(x_i²) + Σ(x_i)) / d
+
0.5
```

Область допустимых решений:

```text
-20 <= x_i <= 20,
i = 1, ..., 6
```

Необходимо найти приближённый глобальный минимум функции.

Известным ориентиром является точка:

```text
x* = (-1, -1, -1, -1, -1, -1)
```

Для неё:

```text
Σ(x_i²) = 6
Σ(x_i) = -6
```

Поэтому:

```text
f(x*) = 0
```

Таким образом, значение `0` используется в работе как ориентир глобального минимума.

Решение представляет собой шестимерный вещественный вектор:

```text
x = (x1, x2, x3, x4, x5, x6)
```

где:

```text
x_i ∈ [-20, 20]
```

Генотип и фенотип в данной работе совпадают.

Дополнительное декодирование решения не требуется.

## 3. Генетический алгоритм

В работе реализован генетический алгоритм со следующими этапами:

1. Создание начальной популяции.
2. Вычисление целевой функции.
3. Сохранение лучших особей.
4. Турнирная селекция родителей.
5. Арифметический кроссовер.
6. Гауссовская мутация.
7. Исправление выхода за допустимые границы.
8. Формирование нового поколения.
9. Повторение процесса до достижения заданного числа поколений.

---

## 4. Инициализация

Каждая координата начальной особи генерируется случайно:

```text
x_i ~ Uniform(-20, 20)
```

Размер популяции:

```text
100
```

что удовлетворяет требованию использовать не менее 30 особей.

---

## 5. Селекция

Используется турнирная селекция.

Размер турнира:

```text
3
```

Из популяции случайным образом выбираются три особи.

Родителем становится особь с наименьшим значением целевой функции.

Преимущество турнирной селекции состоит в том, что для минимизируемой функции не требуется дополнительно преобразовывать значения fitness в положительные вероятности.

---

## 6. Кроссовер

Используется арифметический кроссовер.

Для родителей:

```text
P1
P2
```

случайным образом выбирается:

```text
alpha ∈ [0, 1]
```

Потомки вычисляются как:

```text
C1 = alpha * P1 + (1 - alpha) * P2

C2 = (1 - alpha) * P1 + alpha * P2
```

Вероятность выполнения кроссовера:

```text
0.90
```

Арифметический кроссовер хорошо подходит для вещественного представления, поскольку создаёт новые решения непосредственно в непрерывном пространстве.

---

## 7. Мутация

Используется гауссовская мутация.

Для каждой координаты независимо выполняется проверка вероятности мутации.

Если мутация происходит:

```text
x_i = x_i + N(0, sigma)
```

где:

```text
sigma = 0.5
```

После мутации применяется ограничение:

```text
x_i = max(-20, min(20, x_i))
```

Таким образом, все особи остаются в допустимой области.

---

## 8. Элитизм

В каждом поколении сохраняются две лучшие особи:

```text
elitism = 2
```

Элитизм предотвращает случайную потерю уже найденных хороших решений.

## 16. Почему функция HappyCat является нетривиальной

Функция HappyCat содержит нелинейную составляющую:

```text
|Σ(x_i²) - d|^(1/4)
```

Она зависит одновременно от всех координат решения.

Условие:

```text
Σ(x_i²) ≈ d
```

задаёт область около многомерной гиперсферы.

При этом в функции присутствует дополнительная составляющая:

```text
(0.5 * Σ(x_i²) + Σ(x_i)) / d
```

которая выделяет предпочтительные направления внутри пространства решений.

Поэтому недостаточно просто приблизиться к некоторой сфере — необходимо найти конкретную выгодную область внутри неё.

В шестимерном пространстве Random Search не использует накопленную информацию об уже найденных хороших решениях.

Генетический алгоритм, напротив, использует селекцию, рекомбинацию, мутацию и элитизм для постепенного улучшения популяции.

## 19. Ожидаемый анализ результатов

Хорошим результатом считается получение значения функции, близкого к:

```text
0
```

поскольку:

```text
f(-1, -1, -1, -1, -1, -1) = 0
```

При сравнении двух вероятностей мутации необходимо учитывать не только лучший запуск, но также:

```text
mean
median
std
worst
```

Меньшее среднее и медианное значение свидетельствуют о более высоком среднем качестве алгоритма.

Меньшее стандартное отклонение говорит о большей устойчивости результатов относительно seed.

## 20. Вывод

В лабораторной работе реализован генетический алгоритм для минимизации шестимерной функции HappyCat.

Использованы вещественное представление решений, турнирная селекция, арифметический кроссовер, гауссовская мутация, обработка границ и элитизм.

Для экспериментального исследования выполняется серия из 20 независимых запусков.

Сравниваются две вероятности мутации при неизменных остальных параметрах.

Также реализован Random Search, использующий тот же вычислительный бюджет, что обеспечивает корректность сравнения методов.

Эффективность алгоритма оценивается не по одному удачному запуску, а по статистике серии запусков и графикам сходимости.

Полученный результат можно считать хорошим, если генетический алгоритм стабильно получает значения, существенно более близкие к нулю, чем Random Search.
