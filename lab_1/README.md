# Лабораторная работа №1

## Вариант 19 — функция HappyCat

Цель работы — реализовать генетический алгоритм для многомерной непрерывной оптимизации и исследовать его работу на функции HappyCat.

## Постановка задачи

Для варианта 19:

```text
d = 5 + (19 mod 6) = 6
```

Используется шестимерный вещественный вектор:

```text
x = (x1, x2, x3, x4, x5, x6)
```

Целевая функция:

```text
f(x) =
|Σ(x_i²) - d|^(1/4)
+
(0.5 * Σ(x_i²) + Σ(x_i)) / d
+
0.5
```

Область поиска:

```text
-20 <= x_i <= 20
```

Известная точка глобального минимума:

```text
x = (-1, -1, -1, -1, -1, -1)
```

Для неё:

```text
f(x) = 0
```

## Реализованный генетический алгоритм

В работе используются:

- вещественное представление особи;
- случайная равномерная инициализация;
- турнирная селекция;
- арифметический кроссовер;
- гауссовская мутация;
- восстановление границ методом clipping;
- элитизм;
- остановка по числу поколений.

Основные параметры находятся в:

```text
config.json
```

По умолчанию:

```text
population_size = 100
generations = 300
crossover_probability = 0.90
mutation_sigma = 0.5
tournament_size = 3
elitism = 2
```

## Обязательные эксперименты

В программе автоматически выполняются:

1. 20 независимых запусков ГА.
2. Сравнение двух вероятностей мутации:
   - 0.05;
   - 0.20.
3. Все остальные параметры при сравнении одинаковы.

6. Random Search получает тот же бюджет вычислений функции.

Бюджет одного запуска:

```text
population_size * (generations + 1)
```

При текущих параметрах:

```text
100 * 301 = 30100
```

вычислений функции.

## Операторы

### Турнирная селекция

Случайно выбираются три особи.

Из них родителем становится особь с минимальным значением функции.

### Арифметический кроссовер

Для двух родителей:

```text
P1
P2
```

генерируется:

```text
alpha ∈ [0, 1]
```

После чего:

```text
C1 = alpha * P1 + (1 - alpha) * P2
C2 = (1 - alpha) * P1 + alpha * P2
```

### Гауссовская мутация

Для каждой координаты с вероятностью `mutation_probability` добавляется:

```text
N(0, sigma)
```

После мутации координата ограничивается диапазоном:

```text
[-20, 20]
```

### Элитизм

Две лучшие особи предыдущего поколения автоматически переносятся в следующее поколение.

## Random Search

Random Search генерирует полностью случайные решения:

```text
x_i ~ Uniform(-20, 20)
```

и сохраняет лучшее.

Количество случайных решений равно количеству вычислений функции, используемых ГА.

Поэтому сравнение производится при одинаковом вычислительном бюджете.
