# Лабораторная работа №1 — вариант 5

## Многомерная оптимизация функции Гриванка генетическим алгоритмом

Проект выполнен на Python и рассчитан на запуск в PyCharm. Ключевые операторы генетического алгоритма реализованы самостоятельно, без библиотек готовой эволюционной оптимизации.

## Задача

Для варианта `V = 5` используется функция Гриванка. Размерность:

```text
d = 5 + (V mod 6) = 10
```

Целевая функция:

```text
f(x) = 1 + (1/4000) * sum(x_i^2) - product(cos(x_i / sqrt(i)))
```

для `i = 1..10`, область поиска каждой координаты: `[-600, 600]`.

Известный глобальный минимум находится в точке `x = (0, ..., 0)`, где `f(x) = 0`. Эта информация используется только для интерпретации качества результата, а не самим алгоритмом.

## Что реализовано

- вещественная хромосома из 10 координат;
- случайная инициализация в допустимой области;
- турнирная селекция;
- арифметический кроссовер;
- гауссовская мутация;
- обрезка координат при выходе за границы `[-600, 600]`;
- элитизм;
- воспроизводимые запуски через `seed`;
- 20+ независимых запусков;
- сравнение двух конфигураций, в которых меняется только вероятность мутации;
- Random Search как baseline при том же бюджете вычислений функции;
- CSV с результатами;
- статистика: best, mean, median, std, worst;
- графики сходимости и итогового сравнения.

## Установка в PyCharm

1. Открыть PyCharm → **Open** → выбрать папку проекта.
2. Создать виртуальное окружение: **Settings → Project → Python Interpreter → Add Interpreter → Virtualenv**.
3. Открыть встроенный Terminal и выполнить:

```bash
pip install -r requirements.txt
```

## Запуск

Из терминала PyCharm:

```bash
python main.py
```

По умолчанию выполняются 20 запусков каждой конфигурации и 20 запусков Random Search.

Можно явно задать параметры запуска эксперимента:

```bash
python main.py --runs 20 --seed 2026 --output results
```

`--runs` не может быть меньше 20, поскольку это требование лабораторной работы.

## Эксперимент 1 — влияние вероятности мутации

Сравниваются две конфигурации. Все параметры идентичны, кроме одного фактора:

- A: `mutation_probability = 0.05`;
- B: `mutation_probability = 0.20`.

Это позволяет исследовать влияние вероятности мутации без одновременного изменения остальных параметров.

## Эксперимент 2 — сравнение с Random Search

Random Search генерирует независимые случайные точки в той же области. Число вычислений функции равно бюджету одного запуска ГА, поэтому сравнение выполняется при одинаковом вычислительном бюджете.

## Почему функция Гриванка нетривиальна

Квадратичная составляющая задаёт глобальную тенденцию к центру, а произведение косинусов создаёт множество локальных минимумов. Поэтому поиск только случайными точками плохо использует уже найденную информацию, а простой локальный поиск может остановиться в локальном минимуме. Генетический алгоритм одновременно исследует несколько областей пространства и комбинирует найденные решения.

## Воспроизводимость

Каждому независимому запуску соответствует собственный seed:

```text
seed = base_seed + run_number
```

При одинаковом seed и параметрах программа воспроизводит тот же результат.
