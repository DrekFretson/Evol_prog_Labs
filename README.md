# Evol_prog_Labs

Лабораторные работы по дисциплине «Эволюционное программирование и генетические алгоритмы».

Индивидуальный вариант: **19**.

## Лабораторные работы

### `lab_1` — многомерная непрерывная оптимизация

Оптимизация функции **HappyCat** генетическим алгоритмом.

Основные особенности:

- вариант 19;
- размерность `d = 6`;
- вещественное представление особи;
- турнирная селекция;
- арифметический кроссовер;
- гауссовская мутация;
- элитизм;
- сравнение двух вероятностей мутации;
- сравнение генетического алгоритма с Random Search;
- серия из 20 независимых запусков.

### `lab_2` — дискретная задача с ограничениями

Построение **расписания экзаменов с конфликтами студентов**.

Основные особенности:

- вариант 19;
- представление решения вектором временных слотов;
- 30 экзаменов;
- 120 студентов;
- синтетически генерируемый набор входных данных;
- жёсткие и мягкие ограничения;
- сравнение `repair` и штрафного подхода;
- сравнение uniform и one-point crossover;
- Greedy baseline;
- Random Feasible Search;
- серия из 20 независимых запусков.

### `lab_3` — многокритериальная эволюционная оптимизация

**Управление светофором в симуляции**, вариант 19, трек A.

Оптимизируются три критерия:

- средняя задержка автомобилей;
- максимальная длина очереди;
- число остановок.

Основные особенности:

- собственная реализация NSGA-II;
- доминирование Парето;
- недоминируемая сортировка;
- crowding distance;
- бинарный турнир;
- построение фронта Парето;
- выбор характерных компромиссных решений;
- сравнение NSGA-II с генетическим алгоритмом на основе weighted sum;
- серия из 20 независимых запусков.

```text
Evol_prog_Labs/
├── lab_1/
│   ├── main.py
│   ├── config.json
│   ├── requirements.txt
│   ├── README.md
│   ├── REPORT.md
│   └── results/
│
├── lab_2/
│   ├── main.py
│   ├── generate_data.py
│   ├── config.json

│
└── lab_3/
    ├── main.py
    ├── nsga2.py
    ├── traffic_sim.py
    ├── config.json
    ├── requirements.txt
    ├── README.md
    ├── REPORT.md
    └── results/
```

Каждая лабораторная содержит исходный код, конфигурацию экспериментов, инструкцию запуска, отчёт и результаты серии запусков.

Все стохастические эксперименты используют фиксированные `seed`, что позволяет воспроизводить полученные результаты.

Ключевые эволюционные алгоритмы и операторы реализованы самостоятельно.
