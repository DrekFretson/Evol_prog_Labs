# Evol_prog_Labs

Лабораторные работы по дисциплине «Эволюционное программирование и генетические алгоритмы».

- `lab_1` — многомерная оптимизация функции Гриванка генетическим алгоритмом, вариант 5.
- `lab_2` — выбор комплекта оборудования при бюджете, мощности и совместимости, вариант 5.

Каждая папка содержит код, README, отдельный REPORT.md, конфигурацию экспериментов и результаты.
